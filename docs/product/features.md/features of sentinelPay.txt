# Version 1 Features

Version 1 is intentionally small. Every new feature must answer two questions before being added:

Does it solve a real problem for the user?
Can it be realistically built within the current scope?


- User Login
- User Registration
- Dashboard
- Transactions
- Risk Score
- Rule Engine
- Transaction Details

>Dashboard

The dashboard should show:

Total Transactions
High Risk Transactions
Medium Risk Transactions
Low Risk Transactions
Recent Transactions


>Transaction Management

Add Transaction (for demo/testing)
View Transactions
Search Transactions
Filter Transactions
View Transaction Details

>Rule Engine

Rules such as:

High Amount
New Merchant
Night-Time Transaction
First Transaction
Multiple Failed Attempts (we can simulate this later)


>Investigation Page

When an analyst clicks a transaction, they should see:

Transaction Information
Risk Score
Triggered Rules
Merchant Information
User Information (simulated)
Investigation Status


>Reports (Simple)

Daily Transaction Count
High Risk Count
Fraud Distribution
